# Programming for AI - Assignment 3
This repository contains my Programming for AI Assignment 3.

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required libraries: NumPy, Pandas, and Matplotlib.
4. Open `Assignment3_Programming_for_AI.ipynb`.
5. Select a Python kernel and run all cells from top to bottom.

## Difficult Part
One challenging part was cleaning and processing datasets using NumPy and Pandas, especially handling missing values and performing calculations along different axes.
