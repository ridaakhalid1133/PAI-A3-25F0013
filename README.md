# Programming for AI - Assignment 3

This repository contains my Programming for AI Assignment 3, including the Jupyter notebook, original datasets, and generated visualizations.

## Repository Contents

- `data/`: Provided CSV, NPY, and NPZ datasets.
- `Assignment3_Programming_for_AI.ipynb`: Completed assignment notebook.
- `outputs/`: Generated dashboard image, PDF, and wave animation.
- `README.md`: Project description and instructions.

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required libraries:

   `pip install numpy pandas matplotlib`

4. Open `Assignment3_Programming_for_AI.ipynb`.
5. Select a Python kernel and run all cells from top to bottom.

## Difficult Part

One challenging part was cleaning and processing datasets using NumPy and Pandas, particularly handling missing values and performing calculations along different axes. Creating visualizations and interpreting results also required careful attention to the actual dataset outputs.
